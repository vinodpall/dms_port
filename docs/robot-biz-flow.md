# 机器人业务管理 · 业务流程梳理（源：robot_web dev 分支）

> 本文档是“机器人业务管理”模块的还原依据。先满足主流程，再做扩展设计。

## 0. 核心原则：以「当前机器人」为中心
- 原系统顶栏有全局机器人下拉（`deviceStore.selectedRobotId`），**所有业务（监控、建图、路线、任务、记录、告警）都只针对当前选中的一台机器人**；切换机器人时出现“机器人切换中...”遮罩并刷新该机器人的地图/相机/路线缓存（`robotBootstrap`）。
- 机器人能力判断：`extra_data.rtk === true` → 搭载 RTK，可使用 **INS / MSF / 新建融合地图 / 卫星图**；无 RTK 时这些按钮置灰并提示“当前机器人未搭载RTK设备”。
- 机器人类型：机器狗（有步态、起立/趴下、地形图）/ 无人车（four_wheel，无步态）。

## 1. 定位方式与两条主流程
实时状态来自 `cmdStatus`：`nav`（激光导航）、`ins`、`msf`、`ins_origin`（INS 已初始化）、`track`（循迹录制/运行）、`app_nav_pause`、`app_stop_navtrack`；定位状态 `locStatus.result`。
**三者互斥**：开导航需先关 INS/MSF；开 INS 需先关导航/MSF；开 MSF 需先关导航/INS。`hasNavEnabled = nav || ins || msf` 是录制路线、添加任务点预填坐标、启动任务的共同前置条件。

### 1.1 激光雷达（SLAM）流程
1. **录包建图**：开始录包（输入数据包名）→ 遥控机器人走完区域 → 完成录制；可选“实时建图”（slam_online，弹窗实时查看栅格图 + 位姿）。
2. **生成地图**：选择数据包 + 输入地图名 → 生成点云地图（显示建图进度 %，可“终止”）。
3. **生成栅格地图**：选择地图 → 生成 2D 栅格图（导航/编辑用）。有 RTK 可“新建融合地图”（MSF 录制）。
4. **地图编辑**（可选）：栅格画笔/橡皮擦；功能区（区域/线段）：禁行区、楼梯、斜坡、窄通道、草地，命名、预览、删除。
5. **开启导航**：选择地图 → 开始导航（`controlNavigation action=1 map_name`）→ 必要时**重定位**（在地图上右键拖出方向箭头提交初始位姿）/ 原点设置；查看 激光雷达/IMU/卫星 传感器状态、定位状态。
6. **录制路线**：选地图 → 录制路线（名称自动加前缀 `地图名_`）→ 遥控走一遍 → 停止录制；路线可预览、轨迹平滑、删除；路线编辑：选段删除 / 绘制（直线/曲线、步长）/ Z 值统一 / 撤销 / 重置 / 保存上传；也可手动“新增路线”绘制。
7. **加任务点**：选择路线 → 创建任务组（关键点文件）→ 添加任务（导航中会**用机器人当前位姿预填 X/Y/Z/角度**），字段见 §3。
8. **起点启动任务**：机器人回到路线起点，在导航开启状态下启动循迹任务（§4）。

### 1.2 INS（RTK/GNSS）流程
1. **INS 初始化**（设置 INS 原点 `setInsOrigin`，原点经纬高缓存于 `ins_origin`）——只需做一次，**不重新初始化则原点长期有效**，已录路线/任务点坐标继续可用。
2. **开始 INS**（`insControl`）；地图使用卫星图，坐标为以原点为基准的局部坐标（可换算经纬度）。
3. **录制路线** → **加任务点** → **启动任务**，与激光流程一致，但**不需要录包建图 / 生成栅格地图 / 重定位**。
- MSF（融合定位）：有 RTK 时可选“融合定位 / 卫星定位”两种 MSF 模式，需要先选地图。

## 2. 导航控制面板（原“导航”页）
开始/关闭导航、暂停/恢复导航、暂停/恢复停障、开始/关闭 INS、INS 初始化、开始/关闭 MSF、循迹避障模式（无避障/停障/绕障，循迹任务运行中可改）、开启/关闭 GPS、原点设置、重定位；任务速度 +/-；信息卡：速度、位姿、传感器状态（激光雷达/IMU/卫星）、系统状态（MSF 状态、定位状态）。

## 3. 任务点（waypoint）字段
任务类型（单选/多选，来自 `/taskpoints/{id}/task_type_list`，如可见光拍照、红外测温、表计识别、录像、气体检测、大模型识别…）、X/Y/Z、角度、预置点（打开云台视频 + 方向/变倍/聚焦，设置/转到预置点）、额外事务（按任务类型的参数配置，如大模型提示词）、描述、步态切换（行走/斜坡/越障/楼梯/帧楼梯/帧45°楼梯/L行走/山地/静音）、地形图（实心/镂空/无踢面/累积帧）、到点不停、避障模式、是否常检。
表格操作：编辑、删除、**到点**（让机器人导航到该点）；顶部显示机器人实时 X/Y/Z/角度、任务 ID；“预览”可在地图上查看路线 + 点位。

## 4. 任务执行
- **循迹任务**：选路线 + 任务组 → 开始（前置：无导航暂停、无其他任务运行、`hasNavEnabled`）→ 弹窗设置避障模式、步态 → 启动步骤日志：检查前置状态（狗趴下需先起立）→ 切行走步态 → 非手动模式 → 地形实心 → 导航模块非手动 → 踏步 → 发送启动指令；运行中可暂停/恢复、关闭。
- **发布点任务**：无路线，仅任务组+点位，机器人逐点导航（需激光导航）。
- **多任务组**：按顺序串联多个子任务；子任务字段：启动模式（导航/INS/MSF）、任务组模式（循迹/发布点）、地图、轨迹（发布点无需）、任务组、圈数、避障、步态、地形、原点发布；支持上移/下移、“异常时原地启动”。
- **定时循迹任务**：选循迹路线 + 任务组 + 开始时间（时:分），列表可删除。
- 任务完成弹窗（TaskCompletionDialog）+ 告警弹窗（AlertNotificationDialog）。

## 5. 记录与告警
- **循迹记录**：筛选 地图 / 识别项目 / 时间 / 日志类型（发布点任务/循迹任务/日常巡检）/ 路线 / 任务组；列：时间、地图、任务名称、任务组、实时坐标、识别项目、识别结果、描述、图片（点击预览）；轮次信息、导出、删除。
- **告警**：实时警情（视觉 WebSocket）；告警日志 处理：误报 / 非误报 + 处理描述，处理详情（结果/内容/处理人/时间），位置预览（经纬高）。
- **识别配置**：LLM 提示词（`/vision/{id}/llm_prompts` 增删改）、传感器阈值、摔倒检测（横滚/俯仰角）。
- **操作日志**：用户、IP、设备、类型、描述、结果、时间。
