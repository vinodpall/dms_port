## 与原项目的差异
- 去掉独立登录页、角色切换与退出：沿用训练场平台登录，当前用户取自平台会话。
- 去掉「用户与权限」管理（系统管理仅保留 IP 白名单 / 审计日志 / 系统设置）；`session.can/allowed` 保留接口但恒为有权限。
- 去掉浅色/深色切换，统一为平台深海军蓝 + 青色赛博风（`src/collect/collect.css`，变量同时挂在 `.cl` 与 `html.cl-theme`，弹窗/抽屉同步适配）。
- pinia store id 统一加 `cl-` 前缀，避免与平台 store 冲突。
- 新增依赖：echarts、vue-echarts、three（采集驾驶舱 3D 场景、趋势图）。

## 业务流程（按需求文档重做）

### 设备：按工位 + 槽位，跨场景复用
- 设备挂在**工位**上（工位 A/B…），按类型落到采集方式的**槽位**（VR：头显 + 机械臂 + 相机；UMI：夹爪 + 相机…，见 `constants.ts` `MODE_SLOTS`）。
- **工位套装**（`stores/devices.ts` `KITS`）一键带出整套设备；同一设备可用于不同场景，靠**占用检测**避免两个采集中任务同时使用。
- **标定**移到设备管理，一次性完成、长期有效；仅移位/维修/更换后重新标定。

### 采集任务：每次采集四阶段
任务配置（向导 4 步：场景与方式 → 工位与设备 → 数据集与参数 → 确认）后，每次采集：
1. **设备自检**：连接、电量、存储、延迟、标定、占用；有异常不能开始。
2. **场景复位与采集**：按场景提示复位并确认 → 驾驶舱采集；支持标记、**回退**（丢弃上一条）、备注。
3. **数据校验**：结束本次后自动校验 6 项规则（完整性、时长、丢帧、同步、VR 漂移/UMI 跳变、数值范围）+ 回放抽查；不通过不入库，警告可选带警告入库。
4. **入库上传**：上传 → 转码对齐 → 元数据/缩略图 → 指纹去重 → 推送标注任务池；失败文件进入待重传。
- 无预热步骤。采集任务页另有**采集历史**（来源/状态筛选、批量重传）、**视频上传**、**LeRobot 导入**（校验 4 项后入库，同样推入标注任务池）。

### 标注
- **任务池 / 我的任务**：按场景批量领取（1–10 条）、领取单条、放回任务池。
- **规则预切分**：标准顺序 / 力觉突变。
- 每个切片 6 类内容：基础动作、主物体（必填）、辅助物体、结果、语义描述（5–200 字）、失败原因（失败时必填）。
- 提交前自检；按标注员等级抽检（新人 100%、熟练 30%），未抽中的免检通过。

### 审核
- **待审池 / 我的审核 / 已审**，加急优先并显示时限，批量领取。
- **10 分制**多维评分 + 建议结论；逐段核对；问题按类型与严重度（致命/一般/建议）记录。
- 四种结论：通过 / 修改后通过 / 驳回 / 退回重做（含原因模板）。
- **质量统计**：今日量、通过率、驳回率、均分、结论分布、常见原因、抽检比例设置、标注员绩效与等级。

### 标注字典（统一字典）
动作 / 物体 / 结果 / 失败原因等分级管理，按场景筛选，显示引用计数、启用开关、版本记录；改名自动同步到已有标注。
